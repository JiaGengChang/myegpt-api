The 'commpass' PostgreSQL 17.5 database contains data of 1143 newly diagnosed multiple myeloma patients from the Multiple Myeloma Research Foundation's CoMMpass study (Relating Clinical Outcomes in Multiple Myeloma to Personal Assessment of Genetic Profile; ClinicalTrials.gov ID NCT01454297). LIST OF TABLES (TABLE NAME: TABLE DESCRIPTION):
per_patient: 
Clinical data per patient, indexed by "public_id". Each row represents a unique patient and contains various clinical and demographic attributes. This table contains information that do not change over patient visits e.g. race, gender, age of diagnosis, cancer stage according to the international staging system (ISS), etc.

per_visit: 
Clinical data per visit made by each patient, indexed by "public_id". Each row represents the M-th patient's N-th visit to the clinic, with visit-specific information e.g., blood test results, bone marrow screening report, disease progression. Each patient will have multiple visits and thus multiple rows.

stand_alone_survival: 
Survival data per patient, indexed by "public_id". Contains survival outcomes and related metrics for each patient. Progression-free survival (PFS) is stored as censpfs (event indicator) and pfscdy (time to event in days), while overall survival (OS) is stored as censos (event indicator) and oscdy (time to event in days). 

canonical_ig: 
Immunoglobulin gene translocations detected by Low coverage, Long insert Whole Genome Sequencing, indexed by "public_id". Each column is a gene name which indicates whether the translocation event for the gene occured. Each value is either 0 (no translocation detected) or 1 (translocation detected). The columns are SeqWGS_WHSC1_CALL, SeqWGS_CCND1_CALL, SeqWGS_MAF_CALL, SeqWGS_MYC_CALL, SeqWGS_MAFA_CALL, SeqWGS_MAFB_CALL, SeqWGS_CCND2_CALL, and SeqWGS_CCND3_CALL.

wgs_fish: 
Chromosome arm-level copy number data, indexed by "public_id". Contains copy number of cytobands such as 1q21, 17p13, etc. Also contains copy number of important oncogenes and tumor suppressor genes.

expr:
RNA-Seq gene expression data, indexed by "gene" (Ensembl Gene ID). Enables efficient querying of gene-level tpm or read-count estimates across all samples with RNA-Seq data. The count and tpm fields are float arrays. To filter by sample, obtain indices using `salmon_sample_names` helper table.

expr_metadata:
Gene expression sample metadata. Use this if filtering gene expression by sample. Sample names, public ID, visit number, and tissue type, ordered in the same order of appearance in the `count` and `tpm` fields of the `expr` table.

genome_gatk_cna: 
Copy number alteration segments from GATK, indexed by "public_id" and "sample". Segment_Mean indicates raw mean log ratios of each probe. Segment_Copy_Number indicates the derived integer copy number status (-2, -1, 0, +1, or +2) for the probe. A CN status of 0 is normal, -1 and -2 indicate loss/deletion, +1 and +2 indicate gain/amplification.

gatk_baf: 
Whole exome-sequencing B-allele frequencies from GATK, indexed by "public_id" and "sample". The Segment_Mean column indicates the minor allele frequency (BAF) which ranges from 0-0.5. Unless stated otherwise, a BAF of <0.25 indicates loss of heterozygosity (LoH) of the genomic region surveyed by that probe. Chromosome contains 'chr' prefix, e.g. chr17.

exome_ns_variants: 
Non-synonymous exome variants, indexed by Ensemble stable ID "geneid" and patient identifier "public_id". 

chromothripsis: 
Occurrence of chromothripsis events indexed by "public_id". Events were detected using ShatterSeek algorithm run on copy number and structural variation data. 

gep_scores: 
Gene expression profiling risk scores, also known as GEP risk indices or GEP signatures, indexed by "public_id". 

mutsig_sbs: 
Mutational signatures for Single Base Substitutions (SBS), indexed by "public_id". Signatures were extracted using SigProfiler. 

stand_alone_trtresp: 
Treatment response data per patient, indexed by "public_id". Contains information about patient responses to treatments.

stand_alone_treatment_regimen: 
Treatment regimen data per patient, indexed by "public_id". Each row details the treatment regiment administered to a patient in that step of treatment. 

gene_annotation: 
Gene annotation reference, indexed by "gene_stable_id" and "gene_symbol". Contains gene metadata such as ensembl IDs, gene symbols, gene type (e.g. protein_coding, lncRNA, miRNA), and genomic coordinates (chromosome e.g. chr17, start e.g. 9608793, end e.g., 9753407). This is useful for finding BAF/CNA probes overlapping a gene of interest.

hgnc_nomenclature: 
Reference of aliases for gene symbols, indexed by "gene_stable_id" and "gene_symbol". Contains the Ensembl stable ID, official HGNC-approved gene symbol, alias symbol, alias name, and HGNC ID.
